# House Price Prediction

A Machine Learning project to predict house prices based on various features and generate visual reports.

## Features & What it does
- Performs Exploratory Data Analysis (EDA)
- Trains regression models to predict housing prices
- Automates visualization generation and PDF reports

## How to Run
1. Run the Python project: `python Python_Code/project.py`
2. Generate the PDF report: `python Python_Code/generate_report_pdf.py`
